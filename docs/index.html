Dynamite Doll Wrestling 3D

An all-female 3D wrestling game: eight wrestlers, a fully lit arena with a crowd, titantron, pyro and broadcast-style camera, best-of-three-falls matches, and keyboard, gamepad or touch controls. Both downloads run offline with no account or internet connection.

Windows PC (x64)

Download for Windows
  1. Extract the downloaded ZIP file to a folder (about 370 MB).
  2. Run DynamiteDollWrestling.exe. It opens full screen with Ultra graphics; press F11 or Alt+Enter to switch to a window.

This is a portable desktop app, so there is nothing to install. The app isn't code-signed, so Windows SmartScreen may show "Windows protected your PC". Choose More info, then Run anyway. Graphics quality can be changed in Settings.

Chromebook

Download for Chromebook
  1. Extract the ZIP in the Chromebook Files app.
  2. Open index.html in Chrome.

The Chromebook edition starts on Medium graphics. Choose Low in Settings on older Chromebooks. It also runs in any modern desktop browser.

Recommended for Ultra: Windows 11 64-bit, a current Intel Core i7/i9 or AMD Ryzen 7/9, 16 GB RAM or more, and a recent NVIDIA or AMD graphics card. The game uses WebGL 2 (Direct3D 11 through ANGLE on Windows) with rasterized shadows and bloom. It does not use DirectX 12 ray tracing.
