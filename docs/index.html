Dynamite Doll Wrestling

A 2D all-female wrestling game inspired by classic 8-bit wrestling games.

Chromebook download

Download for Chromebook

Extract the ZIP in the Chromebook Files app, then open index.html in Chrome. This browser edition works offline and needs no installation.

Windows download

Download for Windows (x64)

To play the Windows version:

  1. Extract the downloaded ZIP file.
  2. Run Dynamite_Doll_Wrestling.exe and keep its console window open.
  3. Open http://localhost:5000 in a modern browser.

The download is a self-contained Windows app; no .NET SDK installation is required. MetaMask reward claims need a separately configured reward issuer and are not enabled in this download.

Windows Ultra Edition

Download Ultra Edition for Windows

For high-end PCs and high-refresh-rate 1440p or 4K monitors. Ultra graphics render at your display's native resolution (up to 4K) and full refresh rate, with arena lighting, shadows, particle effects and camera shake.

  1. Extract the downloaded ZIP file.
  2. Double-click Play Dynamite Doll Wrestling Ultra.cmd to play full screen in Microsoft Edge, or open index.html in any modern browser.

No installation or internet connection is needed. The game is 2D and does not use DirectX 12 ray tracing. MetaMask rewards are not available in this edition.
